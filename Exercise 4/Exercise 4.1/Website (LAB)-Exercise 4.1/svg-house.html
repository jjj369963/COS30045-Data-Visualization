Exercise 4.1 — Creating and customising SVG shapes, understanding the coordinate system, and using the group element.

1. Customised SVG Picture — Before & After

The original picture (Before) was constructed using basic SVG primitives (<rect>, <circle>, <polygon>, <path>, and <text>). The customised version (After) adds enhanced visual styling, a linear gradient sky, a pulsing sun (<animate>), clouds (<ellipse>), birds (<polyline>), a chimney (<rect>), flowers, and groups both windows inside a <g> container with transform="translate(x, y)".

2. SVG Coordinate System — Annotated Screenshots (Before & After)

SVGs use a 2D coordinate system with origin (0, 0) at the top-left corner, where the x-axis increases to the right and the y-axis increases downwards. The screenshots below annotate each element to demonstrate how the numerical coordinate values in code map to on-screen positions.

AFTER Customised SVG 
<svg viewBox="0 0 500 500">
  <defs>
    <linearGradient id="skyGrad"
        x1="0%" y1="0%"
        x2="0%" y2="100%">
      <stop offset="0%"
            stop-color="#1a3a6b" />
      <stop offset="100%"
            stop-color="#87CEEB" />
    </linearGradient>
  </defs>

  <!-- Sky with gradient -->
  <rect width="500" height="305"
        fill="url(#skyGrad)" />

  <!-- Grass - richer green -->
  <rect y="305" width="500" height="195"
        fill="#2E8B57" />

  <!-- Sun - moved + pulsing animate -->
  <circle cx="420" cy="80" r="50"
          fill="gold">
    <animate attributeName="r"
             values="45;52;45"
             dur="3s"
             repeatCount="indefinite" />
  </circle>

  <!-- Clouds using ellipse -->
  <g fill="white" opacity="0.9">

  <!-- Birds using polyline -->

4. Code Element Changes Summary

Every SVG element that was added, modified, or grouped between the original and customised versions.

Element (SVG Tag) Change Type Before Code After Code
<linearGradient> in <defs> Added None Deep blue → sky blue gradient for the sky background
<rect> — Sky Modified fill="#87CEEB" fill="url(#skyGrad)" (uses gradient)
<rect> — Grass Modified fill="#008000" fill="#2E8B57" (richer green)
<circle> — Sun Modified cx="404" cy="100" r="40" fill="#FFFF00" Moved to cx="420" cy="80" r="50" fill="gold"; <animate> added for pulsing radius
<ellipse> — Clouds Added (Step 3) None 2 clouds, each made of 3 overlapping <ellipse> elements grouped in <g> with opacity
<polyline> — Birds Added (Step 3) None 3 birds drawn as V-shapes using <polyline points="…"> with fill="none" stroke="#222"
<rect> — Tree Trunk Modified x="80" y="230" width="20" height="125" fill="#8B4513" x="75" y="220" width="30" height="135" fill="#6B3A1F" (wider, taller, darker)
<path> — Tree Leaves Modified fill="#228B22" fill="#32CD32" (brighter lime green)
<rect> — House Base Modified fill="#8B4513" fill="#C0713D" (warmer terracotta)
<rect> — Chimney Added (Step 3) None x="300" y="60" width="30" height="70" fill="gray"
<polygon> — Roof Modified fill="#CD853F" fill="#8B6914" (darker olive-brown)
<g> — Window Group Added (Step 4) Two separate <rect> elements with no shared styling Parent <g fill="…" stroke="…"> with two nested <g transform="translate(x,y)"> children
<rect> — Windows Modified (Step 4) fill="#ADD8E6" (no stroke) fill="#E0F0FF" stroke="#333" stroke-width="2" (inherited from parent <g>)
<line> — Window Cross-bars Added (Step 4) None 4 × <line> (2 per window) inside each window <g>
<rect> — Door Modified fill="#A0522D" fill="#7B3F00" (darker brown)
<circle> — Doorknob Modified r="4" fill="black" r="5" fill="gold"
<circle> — Flowers Added (Step 3) None 3 flowers on the grass; each flower uses 4 petal <circle> + 1 gold centre <circle>
<path> — Garden Path Modified stroke="#FFA500" stroke-width="4" stroke="#aaa" stroke-width="6" (light stone grey, thicker)
<text> — Label Modified fill="black" fill="white" (readable on terracotta wall)
