About This Project

This website was created as part of COS30045 – Data Visualization at Swinburne University of Technology. It focuses on household appliance energy consumption in Australia, with the aim of presenting energy data in a clear and accessible way.

The site was built using HTML, CSS, and JavaScript without any external libraries. It forms the foundation for later exercises involving the D3.js data visualisation library.

Developer

Lim Jun Xian — COS30045 Data Visualization Student, Swinburne University of Technology

Technologies

  • HTML5 — page structure across three pages
  • CSS3 — one external stylesheet shared across all pages, using CSS variables
  • JavaScript — FAQ accordion, energy calculator, and input validation
  • GitHub — version control and repository hosting

Data Sources

Energy figures used on this site are estimates based on:

  • energyrating.gov.au — Australian Government Energy Rating
  • aer.gov.au — Australian Energy Regulator
  • Manufacturer product specifications (Samsung, LG, Sony, Hisense, TCL)
